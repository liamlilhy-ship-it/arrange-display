Arrange Display 1.1.0

In-app updates

Settings now has an Updates section with a Check for Updates… button and the version you are running. The app never checks or downloads anything on its own — it only looks when you ask it to.

Updating this way means macOS does not repeat the first-launch approval steps, because the app installs the update itself rather than handing you a fresh download. Your presets and settings are kept.

Also in this release

  • The app now has a proper icon in Finder and the Dock.
  • Saved presets are protected against a damaged settings file — a file that cannot be read is preserved instead of being overwritten.
  • The minimum system version is now stated correctly as macOS 26.

Arrange Display 1.1.0（中文）

应用内更新

设置中新增了更新一栏，包含检查更新…按钮以及当前版本号。 应用不会自行检查或下载任何内容，只有在你主动点击时才会去查看。

通过这种方式更新时，macOS 不会再次要求你完成首次启动的授权步骤， 因为更新是由应用自身安装的，而不是让你重新下载。你的预设和设置都会保留。

本次更新还包括

  • 应用在访达和程序坞中有了正式图标。
  • 保护已保存的预设：当设置文件损坏无法读取时，会先保留原文件而不是覆盖它。
  • 最低系统版本已更正为 macOS 26。
